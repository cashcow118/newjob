### 1-2. 텔레그램 봇 만들기 (3분)

1. 텔레그램에서 **@BotFather** 검색 → 대화 시작
2. `/newbot` 입력 → 봇 이름·아이디 정하기 → **토큰**을 받습니다 (`8123456789:AAH...` 형식)
3. 방금 만든 봇을 검색해서 **대화 시작(Start)** 을 누릅니다 ← 이걸 안 하면 봇이 메시지를 못 보냅니다
4. 브라우저에서 아래 주소를 열어 `chat_id`를 확인합니다 (토큰 자리에 2번 토큰을 넣으세요)
   ```
   https://api.telegram.org/bot<토큰>/getUpdates
   ```
   결과 중 `"chat":{"id":123456789` 의 숫자가 chat_id 입니다.

### 1-3. 설정 파일 만들기

`config.example.json` → **`config.json`** 으로 복사한 뒤 채웁니다:

```json
{
  "T": 60000000,
  "slot_pct": 0.25,
  "pair_pct": 0.15,
  "empty_slots": 2,
  "discretion_A": 0,
  "discretion_B": 0,
  "semi_weight_pct": "30.7%",
  "event_dday": false,
  "limit_state": "normal",
  "telegram_token": "여기에 봇 토큰",
  "telegram_chat_id": "여기에 chat_id"
}
```

- `limit_state`: `normal` / `half`(월 −5% 도달 → 절반 사이즈) / `stop`(월 −8% 도달 → 실행표 대신 규칙 상기)
- 모르는 값은 `null`로 두세요. 보고서에 **"확인 필요"** 로 찍힙니다. 추정치를 넣지 않습니다.

`holdings.example.csv` → **`holdings.csv`** 로 복사하고 지금 보유 중인 종목을 적습니다. **여기 적힌 종목은 후보에서 빠집니다**(물타기 금지).

## 3. 매일 받는 것

```
① scan_signals.py 100종목 스캔 → scan_res.csv
② 제외 규칙: 보유 종목 / 첫 도달 아닌 −20% 이하 / 당일 +15% 이상 / 우선주·ETF·스팩
③ 4개 기준 판정 → ④ 우선순위대로 정확히 3개 → ⑤ 텔레그램 + reports\후보3선_YYYY-MM-DD.md
```

| 기준 | 판정 방법 | 원천 |
|---|---|---|
| ① 낙폭과대(전략 D) | 60일 고가 −20% **첫 도달** & 거래량 ≥ 20일평균 1.5배 | `scan_res.csv` |
| ① 워치리스트 | −15~−20% → "−20% 선까지 필요 하락폭 + 필요 거래량"을 숫자로 | `scan_res.csv` + FDR |
| ② 짝궁(전략 P) | 삼성전자 등락 − SK하이닉스 등락 ≥ **+3%p** → SK하이닉스. 역방향은 후보 아님. 격차는 신호 없어도 기재 | `scan_res.csv` |
| ③ 외국인 수급 | `foreign.csv` (HTS [0266] 캡처를 옮겨 적은 것) | **없으면 "확인 필요"** |
| ④ 거래량 증가 | 배수 ≥ 2.0 & 등락 −10~+10% | `scan_res.csv` |

**선발 순서**: 1순위 ①신호확정·②짝궁 `[신호·실행가능]` → 2순위 워치리스트 ∩ (③ 또는 ④) `[워치·조건부]` → 3순위 ③·④만 `[관찰·규칙 밖]`.
동순위는 **(1) 반도체·지수 주도 대형주 → (2) 거래량 배수 큰 순 → (3) 낙폭 깊은 순**. 같은 업종 최대 2개.
규칙 내 신호가 3개 이상이면 관찰 종목은 넣지 않습니다.

`[신호·실행가능]` 에만 실행표(전략·수량·지정가·주문시각 14:30~15:20·+5% 절반 익절가·D+10 청산일)가 붙습니다.

## 7. 한계 (정직하게)

- **14:00 봉은 잠정치입니다.** 종가 확정은 15:30이고, 경계 종목은 15:20 전에 다시 봐야 합니다.
- **거부권(DART 공시·뉴스)이 이 보고서에는 자동 반영되지 않습니다.** 원인·거부권 칸은 "확인 필요 · 거부권 미점검"으로 나갑니다. 거부권은 14:35 파이프라인(`news_analyst.py`)이 담당하거나, 후보를 보고 저에게 물어보시면 됩니다.
- **`[관찰·규칙 밖]` 종목은 백테스트 근거가 없습니다.** 실행하시면 재량 카운트이고 사이즈는 절반 슬롯 이하입니다. 거부권을 규칙 밖 종목을 추가하는 데 쓰지 않습니다.
- `kospi100.csv` 는 2026-09 기준입니다. 분기마다 시총 순위가 바뀌므로 갱신이 필요합니다.
- 이 스크립트는 **값을 구하지 못하면 "확인 필요"로 남깁니다.** 추정치로 후보를 만들지 않습니다.
